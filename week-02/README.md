# Week 2
For this week's task, I have transcribed the song "begged" by Olivia Rodrigo into MuseScore. The original arrangement is by vanerian and can be found [here](https://musescore.com/user/115799783/scores/35599229).

I transcribed the score by hand, which was relatively simple and also tedious. You must exit "edit" mode if you want to change a note's duration, ties, or placement on the staff, which was confusing to figure out. The copy and paste feature was useful for phrases that repeat throughout the song.
